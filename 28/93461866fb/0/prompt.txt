## 6. TOOL-SIDE FIXES, RANKED BY EXPECTED TOKEN RECOVERY

**P0 — lift `GQ_SEARCH_CAP=1` for C (or make the cap adaptive: allow search #2 when search #1 returned &lt;50% gold-file bytes / zero `exact-symbol`).**
Evidence: the refused redis query #2 returns `streamTrim` rank-1 complete-symbol in 8,042 B. Recovers the 21,232-tok thinking turn (**445,872 replayed tok = 18% of the redis run**) plus most of the 38,749 B of Reads. This alone flips redis from +30.9%.
Cheap self-check to gate on: payload contains ≥1 `exact-symbol` signal, or ≥50% bytes in one file.

**P1 — print enclosing-symbol TRUE span on every fragment block.**
Site: `internal/cli/search.go:418-427`; needs `SymbolStartLine/SymbolEndLine` on `sem.SearchResult` (`internal/sem/search.go:165`), already available inside `search_enclosure.go`.
Emit: `2. src/main.c:578-583 symbol=umain kind=function span=270-725 (456L, body elided — read 270-725)`.
Converts jq's 3 sweeping reads (26,873 B) into 1 targeted read (~13,000 B). Saves **~13.4 kB × replay**. Also kills the mpy 6-window sweep of `mp_call_prepare_args_n_kw_var` (716–915).

**P2 — raise/soften the 160-line cap for C, or add a skeleton mode for over-cap C bodies.**
160 = C p99 (redis 198 / jq 343 / mpy 157). Options, in order:
 a. skeleton: signature + top-level `if/else/switch/for` scaffold + matched hunk ±20L → bounded ~60 lines for a 456-line function, still tells the agent the shape;
 b. per-language cap: C = 260 (covers mpy 200, redis 198; still excludes jq's 456);
 c. hard: never emit a `symbol=X` fragment without X's bounds (that's P1, which is strictly cheaper).
2 of 3 C golds are over-cap.

**P3 — vendored/third-party path demotion in ranking.**
`lib/oofatfs/ff.c` alone = 3,058 B = **68%** of the mpy payload; `ports/*/boards/*.py`, `extmod/btstack/`, `ports/cc3200/FreeRTOS/` also surfaced. Rule: demote `lib/`, `third_party/`, `vendor/`, `deps/`, `extmod/*/&lt;upstream&gt;/`, and files with no in-repo git churn. Would free ~3 kB of the 4.5 kB mpy payload for `py/runtime.c`.

**P4 — suppress `SAME-CONCEPT LITERAL` when the literal is a dictionary word or &gt;50% of shown hits are `DOC`.**
jq's block: literal `"ASCII"`, 41 hits / 14 files, all 6 shown were `docs/content/manual/*.yml DOC`. Zero value, pure payload tax. redis's (`"xtrim"`) was useful → gate, don't remove.
