# Graph Parser System

## Evidence-Backed Developer Workflows

### Theory, Implementation, and Verification Guide

GPS is the Graph Parser System implemented within the `entire graph` command
namespace. It turns a semantic code graph into an inspectable workflow for
developers and agents.

The system does not claim that static analysis or a passing test proves product
correctness. Instead, it connects explicit product intent, code structure,
change evidence, and test evidence, then identifies the decision a reviewer
must make.

**Document status:** implementation guide for the repository as it exists.

**Primary audience:** developers, reviewers, maintainers, and coding agents.
